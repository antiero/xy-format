Tested on Mac, iPhone and iPad, updating OP–XY OS 1.2.0 to 1.2.1. xybuddy offers native installation of a release only after it has been tested on real hardware on that platform.

01

before updating

Save the current project on OP–XY and stop playback. Use Back Up First, or confirm that you already have a backup or choose to continue without a new one. Unsaved instrument edits are not included in a backup.

Connect one OP–XY by a reliable USB data cable in normal MIDI mode. Keep power stable and close other apps using the instrument. Finish transfers, recording and playback first.

Official firmware only! Custom or modified firmware is not supported. Do not use automatic updating if your OP–XY runs any of these, even if its OS version number looks supported. The version number alone cannot prove firmware is unmodified.

02

native update

On iPhone and iPad, tap Firmware Update in the Files toolbar. On Mac, choose xybuddy › Check for OP-XY Update… in the menu bar, which also refreshes the release check. When a newer OS is available, Mac also shows Update OP-XY in the toolbar, which opens the same sheet.

Tap Check Device to read the installed OS and serial number from OP–XY, then review the available release and release notes. Update OP-XY is offered only for a reviewed firmware image and eligible starting OS. A newly discovered release does not automatically become eligible for installation.

After Check Device, OP–XY can’t switch to MTP mode until it restarts. If you check without updating, turn OP–XY off and on again before using Files or Backup.

Accept the risk and responsibility notice and confirm that the instrument runs official, unmodified teenage engineering firmware. Acceptance is required again for each update attempt.

xybuddy downloads the complete image and verifies its hash, size, version and model before preparing OP–XY. Device transfers, recording and other xybuddy MIDI sends are paused during the update.

Follow the stages: Preparing → Transferring → Installing → Restarting → Verified. Keep xybuddy open and the USB connection and power stable. A completed transfer is not yet a completed installation; success requires the same OP–XY to reconnect and report the expected OS.

Host sleep protection helps, but cannot guarantee uninterrupted operation. iOS may interrupt background work, so keep xybuddy in the foreground. A firmware update also does not remove independent project-format compatibility restrictions.

03

cancellation

Cancel Download stops the download. During preparation or transfer, Cancel Update asks for confirmation before stopping further sends.

Stopping a transfer does not undo bytes already sent or guarantee that OP–XY can continue normally. Keep it powered and connected, follow its screen and use manual recovery if needed. Do not power off the instrument as a way to cancel.

Once installation begins on OP–XY, cancellation is disabled because xybuddy cannot safely undo that operation. Keep the instrument powered until installation and verification finish.

If the session is interrupted, xybuddy retains its recovery record and keeps device access paused. It does not automatically resume, retry, reboot or reset the instrument. After OP–XY has finished and returned to normal MIDI mode, use Check Installed OS or End Update Session; both perform a fresh device check before access is released.

04

risks & responsibility

Official firmware only!

Do not use automatic updating with custom or modified firmware, even if its version number matches.

Updates can leave OP–XY unresponsive or erase data. Back up first. Keep power and USB connected.

This method is not approved by teenage engineering. Use it at your own risk.

05

manual update

Open Manual Update in the update sheet. Download the official firmware and use Save or Share Firmware to save the file or send it to a computer. Downloading the file to an iPhone does not install it on OP–XY.

TE’s documented manual procedure uses a computer: power off OP–XY, hold COM while powering on, press track button 1, connect by USB, copy the official firmware to the removable disk and safely eject it. Then wait and follow the instrument’s screen. Never begin these steps while an installation is still running.
