01

get started

Start with a MIDI file or an existing OP–XY project. Song works without a connected instrument; Files and Backup need a USB connection.

1. open xybuddy

Use the app on iPhone, iPad or Mac. You can also open Song in your browser. The native apps add device file management, backup and USB audio capture.

2. bring in a song

In Song, import a MIDI file or open a .xy project. On Mac, you can also drop a file into the Song workspace. Choose the MIDI tracks you want to use, preview the result and name your project.

3. connect when you’re ready

Connect OP–XY using a USB data cable. For files and backups, choose Enable MTP Mode in the mobile app, use the OP–XY button on Mac, or select COM › M4 on the instrument. Eject when finished to leave MTP mode.

MTP file transfer and USB audio capture are separate modes. Finish and eject file transfers before setting up Capture.

02

song

Turn MIDI into an OP–XY project, or continue working on an existing .xy file.

Import
Open MIDI or an OP–XY project using the import control. Files on a connected OP–XY can also be opened in Song from Files.
Shape
Use Pattern, Arrange and Song views to work with notes, patterns and the song structure. Set tempo, select presets and preview your arrangement.
Export
Export .xy for OP–XY or MIDI for your DAW. In the native apps, send the generated project to the connected instrument. Mac also offers Save as Template.

previewing sound

Local preview is a guide to the notes and arrangement. For the instrument’s own sound, choose an available OP–XY MIDI output and listen to OP–XY. MIDI carries performance data; it does not carry audio.

project compatibility

If a project opens in a read-only or diagnostic view, keep the original file. Use only the export and editing actions offered for that project.

03

edit

iPad + Mac

A native piano roll for working across a linear arrangement. Open your song in Edit, adjust the notes, then send the result back to Song.

on iPad

Tap to add or select a note. Drag to move it, or use the handle beyond its end to change its length. Hold, then drag to select a group. Pan with one finger and pinch to zoom time.

with a keyboard

Use the arrow keys, Delete and ⌘ Z while editing. On Mac, use the pointer to select and move notes.

Returning edits to Song rebuilds the arrangement as four-bar scenes. Review that arrangement before exporting. iPhone has the Song workspace but does not include the separate native Edit room.

04

files

Browse Projects, Templates, Presets and Samples on your connected OP–XY.

  1. Connect by USB and enable MTP mode.
  2. Open Files and choose an area or folder.
  3. Open a project in Song, transfer files, or use the available rename, folder and delete actions.
  4. Wait for the current transfer to finish, then eject.

on Mac

Use ⇧ click to select a range and ⌘ click to add or remove individual items. Drag files out to Finder to download them. Drop .xy projects into the Files view to upload them.

on iPhone and iPad

Use the import control to choose local files and the share sheet to save or share downloaded items. If camera access is requested, allow it: iOS uses that permission for the USB file connection.

Back up before deleting or replacing device files. A name collision may need to be resolved before a transfer can proceed.

05

backup

Keep timestamped snapshots of your OP–XY, locally or in iCloud Drive.

make a snapshot

  1. Connect OP–XY in MTP mode and open Backup.
  2. Choose Full, or Custom to select projects, presets and samples.
  3. Choose whether new backups use iCloud, then create the backup.
  4. Keep OP–XY connected until verification finishes and the snapshot appears in History.

restore with a preview

Choose a backup and the categories to restore. Check the comparison before confirming: it shows new, changed and unchanged files. Restore keeps extra device files and creates a safety snapshot before applying changes.

find your backups

On iPhone and iPad, local backups are in Files › On My iPhone/iPad › XYBuddy › Backups. On Mac, local snapshots are stored in the app’s Application Support folder. iCloud snapshots use the shared XYBuddy backup container, so both platforms can use the same backup format.

If an iOS restore is interrupted, reopen Backup and use the offered Resume Restore or Restore Safety Backup action. Let iCloud finish downloading a backup before restoring it.

06

capture

Record the USB inputs as separate WAV stems on a shared timeline, ready for your DAW.

  1. Finish file transfers and leave MTP mode.
  2. On OP–XY, choose the USB audio mode you want. Its eight-channel mode exposes Tracks 1–8 as mono inputs.
  3. Open Capture, select the USB input and check the meters. Grant audio recording permission when requested.
  4. Choose a destination on Mac. On iPhone and iPad, takes are saved under Files › XYBuddy › Studio Capture.
  5. Record, perform on OP–XY, then stop. Play back the take or open its stem files in your DAW.

monitoring

Enable Monitor only when you need live input playback. On iOS, use headphones or an external output; speaker monitoring is blocked to prevent feedback.

your take

Each session contains one mono WAV per input plus a session.json record. Keep the session folder together. If a cable disconnects or the audio route changes, check the interrupted take before recording again.

08

troubleshooting

OP–XY isn’t appearing in Files

Check the USB data cable, enable MTP mode and scan again. Close other applications using the instrument’s file connection. On iPhone or iPad, check XYBuddy’s camera permission in Settings.

Capture has no input

Leave MTP mode, select OP–XY as the audio input and check its USB audio configuration. Confirm recording permission and look for meter activity before starting a take.

The preview sounds different from OP–XY

The local preview uses a general-purpose sound bank. Send MIDI to OP–XY or export the project to hear it with the instrument’s sounds.

A backup or restore stopped

Reconnect the instrument and reopen Backup. On iOS, follow the recovery actions offered for an interrupted restore. Keep your original snapshot and safety snapshot until you have checked the restored device.

Where can I get help or report a problem?

Report a native app issue or report a Song editor issue. Include your platform, app version, OP–XY firmware and the steps that reproduce it. Share a project only if you’re comfortable making its contents public.

For the instrument itself, see the official OP–XY guide ↗.

09

firmware updates

Native xybuddy builds include an OP–XY OS updater for Mac, iPhone and iPad. Connect by USB in normal MIDI mode and open OS Update. On Mac, you can also choose xybuddy › Check for OP-XY Update… from the menu bar.

Official firmware only! Do not use automatic updating with custom or modified firmware. Save your project, back up and accept the risk notice before each update. Cancellation is available during transfer; once installation begins, keep power and USB connected until verification finishes.

Native installation has been tested on Mac, iPhone and iPad. This independent update method is not approved by teenage engineering and is used at your own risk.
