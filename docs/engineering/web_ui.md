# Web UI Product Requirements

## Desktop operation

- The primary editing controls for a workspace must fit within a 1440 × 900
  desktop viewport without document-level scrolling.
- Dense working surfaces such as the piano roll may scroll internally when
  their content exceeds the available canvas.
- Responsive layouts may stack below the desktop breakpoint, but controls
  needed to complete the active editing task must remain reachable.

## Instrument language

- Mirror the OP-XY's physical control placement when a web control has a clear
  hardware counterpart.
- Use rounded-square hardware pads for direct track, pattern, length, and scale
  selection. Keep icons paired with tooltips and accessible names when a text
  label would make an action unnecessarily wide.
